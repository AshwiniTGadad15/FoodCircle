## 🌍 About FoodCircle

**FoodCircle** is a community-driven food-sharing platform designed to connect people who have extra food with people who need it.

Every day, perfectly usable food goes to waste while many people struggle to access nutritious meals. FoodCircle aims to bridge this gap by bringing individuals, restaurants, hotels, grocery stores, NGOs and volunteers together through one connected digital ecosystem.

Our goal is simple:

> 🍲 Don't waste food. Share it with someone who needs it.

Through technology, community participation and responsible food distribution, FoodCircle aims to create a future where surplus food becomes an opportunity to help someone.

---

## 💚 Our Mission

To reduce food waste by building a connected community where surplus food reaches people who need it.

## 🌱 Our Vision

A world where everyone has access to food, communities support one another, and good food never goes to waste unnecessarily.

## ⚡ How FoodCircle Works

  <img src="https://img.shields.io/badge/01-REGISTER-16834A?style=for-the-badge" />
  <img src="https://img.shields.io/badge/02-SHARE%20FOOD-56B870?style=for-the-badge" />

**Step 1 — Join the Community**

Create an account as a donor, food seeker, volunteer or organization.

**Step 2 — Share Surplus Food**

Donors upload available food with quantity, images, location and safe consumption details.

**Step 3 — Connect With People**

People in need and registered organizations discover available donations and submit requests.

**Step 4 — Collect and Distribute**

Donors approve requests, and recipients or volunteers coordinate safe food collection.

**Step 5 — Make an Impact**

Completed activities contribute to the community's food-sharing impact.

## 💻 Getting Started

Follow these steps to run FoodCircle locally.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/FoodCircle.git
```

### 2. Navigate to the Project

```bash
cd FoodCircle
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file and add the required configuration:

```env
VITE_API_URL=
MONGODB_URI=
FIREBASE_API_KEY=
CLOUDINARY_CLOUD_NAME=
```

Use the actual environment variable names required by your implementation. Keep all private credentials on the server.

### 5. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal.
